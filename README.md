# ESP32-S3 Tri-Mode Voice Rover
基于 ESP32-S3 的多模式 AI 语音控制移动机器人，ESP-IDF 开发

## 项目简介
支持三种控制模式自由切换：
1. **离线语音模式**：使用 ESP-SR 本地语音唤醒+关键词识别，I2S 数字麦克风采集音频，内置AFE降噪，无需联网即可识别预设指令
2. **WiFi联网模式**：WiFi连接，音频上传云端ASR，支持自然语言控制
3. **蓝牙遥控模式**：手机蓝牙下发指令，作为备用控制通道

固件实现：PWM电机调速、状态机管理模式切换、超声波避障逻辑
硬件：嘉立创EDA绘制两层底板，包含电源、L298N电机驱动、I2S麦克风、超声波传感器接口

## 开发环境
- 主控：ESP32-S3
- 框架：ESP-IDF
- 语音库：ESP-SR
- 硬件设计：嘉立创EDA
